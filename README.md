# DMX MASTER

Sistema ERP ligero basado en Google Apps Script para gestión comercial multi vendedor.

## 🚀 Características
- Gestión centralizada de ventas
- Control de inventario con bloqueo
- CRM dinámico
- Reportes automáticos
- Generación de PDF
- Sistema multi vendedor
